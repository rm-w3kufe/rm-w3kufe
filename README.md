## rm-w3kufe

Systems research. Cybersecurity. AI governance.

---

I build infrastructure that governs itself.

Current focus: **VSF** (Viable System Framework) — a formal governance layer for AI systems and distributed infrastructure, based on Stafford Beer's Viable System Model (1972). Includes a Rust kernel (`vsf-nucleus`) that executes viability axioms at runtime: trust scoring, resource budgets, recursive subsystem spawning, and algedonic signaling.

The goal is a governance primitive you can embed anywhere a system needs to remain viable under pressure.
